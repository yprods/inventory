# Quick Start Guide

## 1. Install Dependencies
```bash
npm install
```

## 2. Configure Environment
```bash
copy .env.example .env
```
Edit `.env` and set your database credentials.

## 3. Start Server
```bash
npm start
```

## 4. Access Application
- URL: http://localhost:1212
- PIN: 4231 (default, change in `.env`)

## That's it! 🚀
